# TennisMirror — правила проекта

PWA на React + TypeScript + Vite для тренировки техники настольного тенниса:
камера телефона и эталонный контент (видео/фото) на одном экране.
Хостинг — Vercel (Hobby), файлы паков — Cloudflare R2. Полный план: [docs/PLAN.md](docs/PLAN.md).

## Жёсткие правила

1. **Не больше 400 строк в любом файле кода** (`.ts`, `.tsx`, `.js`, `.mjs`, `.css`, `.html`).
   Считаются все строки, включая пустые и комментарии. Если файл подходит к лимиту —
   сначала разделить его по ответственности, потом добавлять код.
   Проверки: ESLint `max-lines` и `npm run check:lines`; второй входит в `npm run build`,
   поэтому сборка на Vercel падает при нарушении. Исключения: lock-файлы, `dist/`, сгенерированные файлы.
2. **Минимум анимаций.** Никаких анимационных библиотек. CSS `transition`/`animation` по умолчанию не используем.
3. **Никаких UI-китов и тяжёлых зависимостей.** Новая runtime-зависимость — только с обоснованием.
   Бюджет JS — не больше 90 КБ gzip.
4. **`<video>` камеры и контента не размонтируются** при смене режима, раскладки или поворота.
   Режимы переключаются только классами/`data-*` атрибутами на корневом элементе.
5. **Частые обновления идут мимо React.** Перетаскивание разделителя, щипок, пан, слайдер прозрачности
   во время движения пишут в `style`/CSS-переменные через ref в `requestAnimationFrame`.
   В store попадает только итоговое значение.
6. **Portrait/landscape и swap — только CSS** (`@media (orientation: landscape)`, `flex-direction`), не JS.
7. **Возможности платформы — через проверку поддержки** (`'zoom' in caps`, `MediaRecorder.isTypeSupported`),
   никогда через user agent.
8. **Зум камеры — только нативный** (`zoom`-констрейнт трека или переключение объективов).
   Цифровой зум (CSS `scale`, кроп через canvas) для камеры не делаем. Зум контента (щипок по эталону) — можно.
9. **Сейчас только личная локальная версия** (фазы 0–7). Vercel, R2 и загрузку записей в облако не подключаем
   до фазы 8. Аккаунты, оплату, аналитику не добавляем. Доступ к пакам — только через `packs/api.ts`,
   записи в облако — только через `recordings/cloud.ts`, чтобы облако и коммерцию добавить в одном месте.

## Команды

- `npm run dev` — dev-сервер на http://localhost:5173 (если порт занят — на следующем свободном).
- `npm run dev:https` — dev-сервер с самоподписанным HTTPS, открыт в сети (для телефона в той же сети).
- `npm run lint` — ESLint + проверка 400 строк. `npm run build` — проверка 400 строк, типы, сборка.
- `/probe.html` — проверка камеры на устройстве: зум, объективы, кадры/с, форматы записи.

## Соглашения

- TypeScript `strict`, функциональные компоненты и хуки, состояние UI — Zustand с селекторами.
- Код группируется по фичам: `camera/`, `content/`, `layout/`, `overlay/`, `gestures/`, `packs/`, `platform/`, `ui/`.
- Целевые устройства: iPhone 16 Pro (Safari и PWA с домашнего экрана) и планшет Digma Pro Evolution 12.6″
  (Android 15, Chrome, Helio G99). Производительность мерить на планшете — он слабее.
  Раскладка должна работать и на телефоне 6.3″, и на планшете 12.6″.
- `getUserMedia` работает только по HTTPS. Dev на телефоне: `cloudflared tunnel --url http://localhost:5173`.
